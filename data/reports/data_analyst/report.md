# Отчет Data Analyst: Exploratory Data Analysis (EDA)

## 1. Контекст и бизнес-задача
В рамках проекта разрабатывается ML-модель бинарной классификации для выявления мошеннических вакансий (Fake Job Postings) на HR-платформе. 
**Бизнес-цель:** Автоматизация модерации, снижение нагрузки на ручных модераторов и защита соискателей от скама.
**Ключевая метрика:** F1-score и Recall по классу 1 (Fraudulent) при удержании приемлемого уровня Precision.

Данный отчет описывает структуру проведенного разведочного анализа данных (EDA) на базе очищенного датасета, подготовленного Data Engineer.

## 2. Структура датасета
В ходе анализа датасет был разделен на две логические группы:
*   **Текстовые признаки (as_is):** `title`, `location`, `department`, `salary_range`, `company_profile`, `description`, `requirements`, `benefits`. Эти поля требуют дальнейшей NLP-обработки (векторизации) на стороне Data Scientist.
*   **Числовые и закодированные признаки:** Включают оригинальные числовые метрики, а также категориальные признаки, закодированные через One-Hot Encoding (OHE) и Frequency Encoding.

## 3. Анализ целевой переменной (Target)
Первым шагом была оценена целевая переменная `fraudulent`. 
*   Выведены абсолютные и относительные частоты классов.
*   Рассчитан **Imbalance Ratio** (соотношение легитимных вакансий к мошенническим). 
*   Построены Bar Chart и Pie Chart для визуализации дисбаланса. Сильный дисбаланс потребует от DS-команды применения техник сэмплирования (SMOTE, class weights) при обучении модели.

## 4. Взаимосвязь признаков с Target
Для понимания того, какие из очищенных признаков обладают наибольшей предиктивной силой, был проведен корреляционный анализ:
*   Рассчитана матрица корреляций Пирсона.
*   Выведен Топ-10 признаков по модулю корреляции с таргетом.
*   Построена тепловая карта (Heatmap) для топ-15 признаков, чтобы выявить не только связь с таргетом, но и мультиколлинеарность между самими фичами.
*   Построены графики наложения плотностей (Overlapping Histograms) для двух самых сильных числовых признаков, чтобы визуально оценить разделимость классов.

## 5. Анализ бинарных (OHE) признаков
Так как низкокардинальные категориальные признаки были закодированы через OHE, мы динамически выделили бинарные колонки (содержащие только 0 и 1).
*   Для каждой бинарной колонки рассчитана вероятность мошенничества (Mean Target Rate) при значении 0 и 1.
*   Выведен Топ-5 признаков с наибольшей разницей в вероятности фрода.
*   Построены столбчатые диаграммы (Bar Charts) для визуализации влияния топ-3 бинарных флагов на таргет.

## 6. Анализ текстовых признаков (Мета-данные)
Хотя сами тексты не векторизовались в рамках EDA, мы извлекли из них полезные мета-признаки:
*   **Word Count (Длина текста):** Рассчитано среднее количество слов в каждом текстовом поле в разрезе классов (Fraud vs Legit). Построено распределение длины для ключевого поля `description`.
*   **NaN Rate (Доля пропусков):** Рассчитана доля пропущенных значений для каждого текстового поля по классам. Построен сгруппированный Bar Chart. Это позволяет проверить гипотезу: *склонны ли мошенники оставлять определенные поля (например, company_profile) пустыми чаще, чем реальные работодатели?*

## 7. Итоги
Ноутбук успешно генерирует 11 содержательных графиков (Plotly) и выводит ключевые статистические метрики в stdout. Данный пайплайн не модифицирует исходный очищенный датасет и полностью готов к передаче на следующий этап (Analyze Node), где из распечатанных чисел будут автоматически извлечены конкретные бизнес-инсайты для финального отчета.
