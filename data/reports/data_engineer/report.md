# Data Engineer Report

## Контекст

Данные исходят из файла `data/raw/fake_job_postings.csv`. Цель очистки — подготовить датасет для задачи бинарной классификации мошеннических вакансий (target: `fraudulent`). Это позволит снизить ручную модерацию и защитить пользователей от скам-постингов. Метрика приоритетна на F1 и recall класса 1 при контроле precision.

## Анализ данных

- Размер датасета и количество пропусков были изучены.
- Определены типы данных по колонкам: числовые, категориальные и текстовые.
- Выявлены колонки с большим количеством пропусков (>70%), которые были удалены.
- Проанализировано распределение целевой переменной `fraudulent`.

## Стратегия очистки

- Колонки с более чем 70% пропусков удалены, чтобы не вносить шум и не усложнять модель.
- В числовых колонках применён клиппинг по 1 и 99 перцентилям для устранения выбросов.
- Пропуски в числовых колонках заполнены медианой или средним в зависимости от наличия выбросов (оценка по скошенности).
- В категориальных колонках пропуски заполнены модой.
- Категориальные колонки с менее чем 20 уникальными значениями закодированы one-hot encoding для сохранения информации.
- Категориальные колонки с более чем 50 уникальными значениями закодированы frequency encoding для предотвращения взрыва размерности.
- Текстовые колонки оставлены без изменений, чтобы DS мог самостоятельно решать, как их использовать.
- Целевая колонка `fraudulent` не изменялась.
